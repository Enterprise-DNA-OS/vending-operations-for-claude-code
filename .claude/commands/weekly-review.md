Run `npm run vending -- weekly-review --json`.

Write it as five short sections: this week (attention), the routes (machines due), money (cash gaps and commission owed), machines (lowest and highest earners) and compliance, then the three actions for the week. Offer `/draft-weekly-review` to save it.
