---
description: Draft the monthly commission statement to a host: machines, visits, collected, GST and the commission on the agreed basis.
---

Run `npm run vending -- draft-commission <site> [YYYY-MM]`. The month defaults to last month.

Show the draft. It is saved to `drafts/` and is never sent from here: the operator sends it from their own email. For the branded HTML version: `npm run docs -- commission-statement`.
